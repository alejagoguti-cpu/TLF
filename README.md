# Hotel La Fontana · Unicentro — modelo 3D web

Visor CesiumJS navegable (pivotear, inclinar, acercar) del entorno del Hotel Estelar La Fontana y Unicentro, Bogotá.

- `modelo/ciudad.glb`: edificios, cubiertas, vías, andenes, separadores, canal y terreno (texturas PBR horneadas, Draco).
- `modelo/arboles.glb`: 9.025 árboles del catastro, impostores de los escaneos PolyHaven usados en Unreal.
- `geo.json`: georreferencia (EPSG:9377 → WGS84) y polígono de recorte de Google 3D.
- `config.js`: llave pública de Cesium ion o Google Map Tiles para el contexto fotorrealista.
